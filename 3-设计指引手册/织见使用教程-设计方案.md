# 织见 · 使用教程设计方案（v2.0 精简版）

> 版本：v2.0 | 日期：2026-08-30 | 定位：基于「织见·思维关系板」核心功能 + AI 接口（v1.1）+ zhijian skill 的画布内教程
> 原则：**教程本身就是织见作品——树少网密，用连接讲连接，用聚焦讲聚焦**。不按功能拆十六张画布，而是"一张讲理念、一张讲基础、少量画布讲复杂与示例"。

---

## 一、整体架构：3+1 张画布

```
织见学堂（项目，推荐名）
├── 画布 01-设计理念与功能全览   ← 一张网讲清“聚焦×连接”理念 + 全部功能映射
├── 画布 02-基础功能讲解          ← 一张画布讲透日常操作（导图+批注+附件）
├── 画布 03-AI 协作与 skill       ← 复杂功能展开①：AI 接口接入 + skill 用法
└── 画布 04-端到端示例合集        ← 展开②：3 个完整使用示例（含 AI 生成导图演示）
```

**为什么只要 4 张**：
1. **聚焦与连接是理念不是功能清单**——功能讲再多不如一张网展示"连接"本身；画布 01 本身就是连接示范。
2. 基础操作（节点/便签/附件/布局/快捷键等）**密度低、彼此互联少**，一张画布用导图分支 + 批注 + 附件即可讲完，拆开反而断网。
3. 只有**真正复杂或需要演示**的才单独开画布：AI 接口（27 命令）、端到端示例（流程长）。
4. 画布间少量跃迁（01↔03↔04），**不为导航而导航**——只设必要的返回与跳转。

## 三、书写模板（统一风格）

画布 01 用「理念→功能→连接」自由网布局（不套模板，模版本身就是示范）；
画布 02/03/04 统一五段式骨架：

```
根节点（画布名，批注=↗返回01或下一步提示）
 ├─ 1 功能简介     ← 一级节点；展开内容写“是什么/解决什么/入口”
 ├─ 2 操作步骤     ← 子节点间 `支撑` 串联成流程图；每步批注写快捷键/图标
 ├─ 3 关键参数说明 ← 子节点=参数，挂附件承载参数表
 ├─ 4 常见问题     ← 子节点=QA；`反证`连接指向易错步骤
 └─ 5 使用示例     ← 子节点=逐步示例，结果挂截图附件
```

连接语义：`支撑`=流程推进 / `导致`=因果 / `反证`=易错或反例；基础元素承载规范与前版一致（节点=功能、连接=流程、附件=参数表、批注=结论、颜色=模块分区）。

## 四、示例画布草稿：画布 01-设计理念与功能全览

**布局**：中心根节点「聚焦 × 连接」，左分支=连接主题、右分支=聚焦主题；中心下方=功能网格（父节点分 4 组：基础/结构/进阶/AI）；最下方=学习路径节点（链接 02/03/04 的跃迁）。

```
                      ┌── 连接（织宽）──┐
                      │  语义连接/批注/跃迁   │
        ┌─ 理念双主旨 ─┤                       │
        │             └── 聚焦（钻深）──┐
        │                       │  展开内容/聚焦模式/搜索  │
根：聚焦 × 连接（中心）
        │
        ├─ 功能网格 ├─ 基础组：画布/节点/便签/附件→  各节点 `支撑` 连向“连接”或“聚焦”
        │   ├─ 结构组：语义连接/批注/展开内容
        │   ├─ 进阶组：布局/样式/背景/聚焦/项目
        │   └─ AI组：AI接口 / skill        ← 子节点跃迁到 03
        └─ 学习路径：01→02→03→04           ← 各节点跃迁到对应画布
```

**连接关系说明**：
- 根↔理念/功能网格/学习路径：父子结构；
- 功能网格里每个功能节点用 `支撑` 连到「连接」或「聚焦」主题——**当场演示语义连接**；
- AI 组节点挂跃迁到画布 03；学习路径 4 节点分别跃迁到 01…04；
- 根节点批注：「按 F 聚焦任意功能点看它的理念连接」——把聚焦也示范了。

**落地顺序**：先建画布 01 → 验证 "一张画布讲理念 + 示范连接聚焦" → 02 基础（导图+批注+附件）→ 03 AI → 04 示例 → 导出 .board.json 归档到 skill 验收样例。

## 五、与原方案差异（为什么改）

| 项 | v1.0（16 画布） | v2.0（4 画布） |
|---|---|---|
| 理念 | 按功能拆抽屉 | 教程即作品，用连接讲连接 |
| 画布数 | 16 | 4（01 理念 / 02 基础 / 03 AI / 04 示例） |
| 导航 | 16 画布互相跃迁（重的导航负担） | 仅必要跃迁：01→03/04、学习路径；少而准 |
| 基础功能 | 每项一画布 | 一张画布用 导图分支+批注+附件 讲完 |
| 复杂功能 | 与其他同级 | 单独画布：AI 接口、端到端示例 |
| 命名 | 使用教程 | 织见学堂（更产品化、契合“学堂”定位） |

> 核心理解复核：你要的是**用最少画布讲清"聚焦+连接"理念与基础**，复杂功能单独展开、实例单独示范，并归入一个像样的文件夹名。以上 v2.0 即此意——4 张画布，树少网密。
