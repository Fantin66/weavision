# 织见 · 材质系统方法论规则文档

> **状态**：设计规范定稿（2026-09-03），尚未实施。
> **目的**：替换当前 ad-hoc `[data-style="..."] !important` 手搓覆盖，标准化所有预设的 chrome 适配与背景处理。
> **原则**：本文件是所有材质、配色、chrome 适配决策的唯一真相来源。实施时以此为准，不以当前代码的零散参数为凭。

## 0. 核心决策摘要

| 决策项 | 结论 |
|---|---|
| 材质作为地板还是可选主题 | **地板**。所有材质预设共享 L1–L7 层栈基底；纹理是材质的滤镜变体，不是平行主题。 |
| `clear`（默认）归宿 | **Mica 基底**（不透明、克制）。当前装饰性 Acrylic 移交给 `glass`。 |
| 玻璃拆分（透明玻璃 vs 毛玻璃） | **不拆**。`clear`=Mica 不透明，`glass`=重模糊毛玻璃（修正当前"太透"）。透明玻璃美学暂不做。 |
| 拟态与 Fluent 冲突 | 共享层栈工程，通过**材质变体**分叉视觉语言。拟态 = Fluent Mica 的"静默模式"（关掉漂移、L2 改均匀实色、L6 改柔影）。 |
| 简约归属 | **反材质预设**，主动退出层栈（L1/L3/L4 全关，L2 纯实色）。不是"低强度 Fluent"，是独立设计立场。 |
| 多彩家族配色 | bento + editorial = **真多彩**（左栏项目/画布/资源库分色，上栏分色）。其他预设 = 单色蓝强调。 |
| 多彩分色规则 | **不写死固定映射**。原则：用高级色彩、同饱和度族、看着舒服。具体落点实现时按美感调。 |
| 底色牵引漂移色板 | 底色色族决定漂移色板色族（牛皮纸→暖族，淡蓝→冷族）。 |
| 节点分档待遇 | 根/主分支节点 = 全套处理；叶节点 = 简化版。 |

## 1. 设计哲学与变体框架

### 1.1 三种设计哲学

| 哲学 | 核心原则 | 适配预设 |
|---|---|---|
| **Fluent** | 元素独立于表面、半透明、发光、多色族、多层分明 | clear, glass, bento, editorial |
| **拟态（Neumorph）** | 元素即表面、柔和阴影挤出感、单色族、不透明不发光 | neumorph, colorful |
| **反材质（Minimal）** | 去掉一切装饰、平实、留白与字号节奏代替材质 | minimal |

### 1.2 材质变体定义

**变体 = 同一七层栈的不同填充规则。** 工程统一（同一套层栈、同一套 blend 规则框架），视觉语言有意分叉。

| 变体 | 触发预设 | 关键差异 |
|---|---|---|
| Fluent | clear, glass, bento, editorial | L1 漂移 ON / L2 主题色 Mica / L6 渐变+发光+Acrylic |
| 拟态 | neumorph, colorful | L1 漂移 OFF（或极弱单色）/ L2 均匀实色 / L6 柔和阴影代替发光 |
| 反材质 | minimal | L1/L3/L4 全 OFF / L2 纯实色无渐变无噪点 / L6 平色+细边框 |

### 1.3 预设 → 变体 + 配色模式 映射

| 预设 | key | 变体 | 配色模式 | 圆角 | 字体 |
|---|---|---|---|---|---|
| 默认 | `clear` | Fluent | 单色蓝 | 8px | 跟随用户 |
| 玻璃 | `glass` | Fluent（满 Acrylic） | 单色蓝 | 14px | 跟随用户 |
| 新拟态 | `neumorph` | 拟态 | 单色（同色族） | 14px | 强制 serif |
| 多彩拟态 | `colorful` | 拟态（彩色版） | 多色 | 16px | 跟随用户 |
| 多彩圆角 | `bento` | Fluent + 多彩 | 多色 | 20px | 跟随用户 |
| 多彩矩形 | `editorial` | Fluent + 多彩（印刷感） | 多色 | 4px | 强制 serif |
| 简约 | `minimal` | 反材质 | 单色蓝 | 4px | 强制 serif |

**多彩家族**（bento + editorial）= Fluent 变体 + 多色配色模式的组合，差异在圆角大小 + 字体。`colorful` 虽标"多彩拟态"但归拟态变体（保留拟态柔影，加彩色表面）。

## 2. 七层栈规范

### 2.1 完整层级定义

| 层 | 名称 | 内容 | 不透明度 | Blend 模式 | 常开/预设 |
|---|---|---|---|---|---|
| L1 | 漂移色 | 3–5 个大 `radial-gradient` 色块，`blur(80–150px)`，超慢 `transform` 动画（周期 60–180s） | 30–50%/块 | normal | 常开，**色板随预设** |
| L2 | Mica 材质面 | 接近不透明的主题色 + 极淡纵向渐变 | 80–92% | normal | 常开 |
| L3 | 噪点纹理 | 单个共享 SVG turbulence，全屏铺 | 3–8% | overlay | 常开 |
| L4 | 图案滤镜 | 横格/方格/点阵/无 | 4–10% | soft-light | **唯一预设变量** |
| L5 | 画布 | pan/zoom 坐标变换容器，自身透明 | — | — | 常开 |
| L6 | 节点 | 渐变填充 + 可选溢出色块 + hover 光 | 分档 | — | 分档待遇 |
| L7 | UI chrome | 厚 Mica 面板 + 极淡边线 | 92–98% | normal | 常开 |

### 2.2 关键架构决定

1. **L1–L4 固定在视口，不跟画布走。** 材质 = "房间"，画布 = "桌面上的纸"。pan/zoom 时节点动，房间不动。背景动画与画布交互物理分离，互不重渲染。L5 画布透明 → 材质铺到视口边缘 = 沉浸感。

2. **Mica ≠ Acrylic。chrome 不用 `backdrop-filter`。** 顶栏/左栏 = 不透明 Mica（92–98%）+ 纵向渐变 + 噪点，不透视背后内容。`backdrop-filter` 只在两处用：节点 Acrylic（L6，分档）和 `#dockBar`（小面积悬浮元素，性能可接受）。

3. **L3 噪点是"质感地板"。** 3–8% 几乎看不见，拿掉立刻变"廉价 CSS 渐变"。一个共享 SVG data URI，性能近零。

4. **L4 是唯一预设变量。** 加新纹理 = 一个 SVG 图案 + 一行 blend 规则，不动其他层。不透明度必须 ≤10%，否则盖过 L2/L3，材质反成配角（本末倒置）。

5. **画布层（L5）透明，不画背景。** 当前代码在 canvas 上画纯色底 + 纹理 + 晕影——升级后这些全移到 L1–L4 DOM 层，canvas 只画节点和连线。

## 3. 材质变体规则（每层填什么）

### 3.1 Fluent 变体

| 层 | 填充规则 |
|---|---|
| L1 漂移 | **ON**，5 色漂移色板（同饱和度族），`blur(80–150px)`，周期 60–180s |
| L2 Mica | 主题色（取漂移色板均值衍生），80–92% 不透明 + 极淡纵向渐变 |
| L3 噪点 | ON，3–8%，overlay |
| L4 图案 | 预设可选，4–10%，soft-light |
| L6 节点 | 渐变填充 + 背后溢出色块（`blur(30px)`，比节点大一号）+ `backdrop-filter` Acrylic（分档）+ hover 跟随光（`mix-blend-mode: screen`） |
| L7 chrome | 厚 Mica（92–98%）+ 极淡边线 + 噪点 |

**glass 子变体差异**（Fluent 变体内的加强版）：
- L2 Mica 更薄（50–70% 不透明）
- L7 chrome 开启 `backdrop-filter: blur(30px) saturate(190%)`——顶栏/左栏变半透明毛玻璃（这是 glass 的特征，其他 Fluent 预设 chrome 不开 backdrop-filter）
- L6 节点加对角高光带 + 底部反射条

### 3.2 拟态变体

| 层 | 填充规则 |
|---|---|
| L1 漂移 | **OFF**（或极弱单色同色族漂移） |
| L2 Mica | **均匀实色**（拟态的"表面"），无纵向渐变。色值：`#f2f3f6`（亮）/ `#2e2e34`（暗） |
| L3 噪点 | ON（保留质感） |
| L4 图案 | 预设可选，更弱（≤6%） |
| L6 节点 | **柔和双向阴影**代替发光——亮影左上 `rgba(255,255,255,.95)` + 暗影右下 `rgba(28,42,74,.14)`，选中时改内凹（inset shadow）。单色族。`colorful` 加彩色表面（`shadeColor(it.color,1.15)`）但保留双向阴影 |
| L7 chrome | 均匀实色 + 柔影边线，无 `backdrop-filter`，无装饰性 `::before` |

### 3.3 反材质（简约）

| 层 | 填充规则 |
|---|---|
| L1 漂移 | **OFF** |
| L2 Mica | **纯实色**，无渐变、无噪点 |
| L3 噪点 | **OFF** |
| L4 图案 | **OFF**（或极弱 ≤3%） |
| L6 节点 | 平色填充 + 细边框（按层级深浅），无渐变、无阴影、无发光。`fontScale: 1.14`（最大字号缩放——靠类型层级而非装饰） |
| L7 chrome | 平实 + 1px 发丝边框，无阴影、无模糊、无渐变 |

## 4. 配色纪律

### 4.1 配色模式轴

| 模式 | 适用预设 | 规则 |
|---|---|---|
| 单色强调 | clear, glass, neumorph, colorful(?), minimal | 强调色 = 蓝色族（`#2d5fd3` 系），所有交互元素统一 |
| 多色分块 | bento, editorial | 左栏项目/画布/资源库各一色，上栏元素分色 |

> **`colorful` 配色模式待定**：它标"多彩拟态"，但归拟态变体。它的"多彩"是指节点表面彩色（`shadeColor`），还是也走左栏分色？实现时按视觉决定，倾向节点彩色 + 左栏仍单色（避免拟态变体里混入多色 chrome 规则增加复杂度）。

### 4.2 漂移色板规则

1. 每预设手调一套 5 色漂移色板，同饱和度族。
2. Mica 主题色（L2）取漂移色板均值衍生，不是另起一个色。
3. 节点渐变色取自同一色板族。
4. 所有层在颜色上是"亲戚"，不是"陌生人拼贴"。

### 4.3 底色牵引漂移色板

底色（用户通过 `#bgColorBtn` 选择）决定漂移色板色族：

| 底色 | key | 漂移色族 |
|---|---|---|
| 白 | `default` | 中性 |
| 护眼绿 | `eye` | 绿色族 |
| 米黄 | `cream` | 暖色族 |
| 淡蓝 | `blue` | 冷色族 |
| 牛皮纸 | `kraft` | 暖色族 |

> 规则：底色色族 = 漂移色板色族。否则漂移色与底色会打架。牛皮纸本质是黄，只要几个底色做得够好看不土，跨样式适配就 OK——但漂移色板要跟着色族走。

### 4.4 多彩家族分色规则

**原则（不写死映射）**：
- 分色对象：左栏三个 section（项目 / 画布 / 资源库），上栏待定（候选：六个菜单标签 布局/样式/添加/关联/字体/查看，或工具组）。
- 色彩要求：高级色彩、同饱和度族、不用原色（不用纯红绿蓝）。
- 不预设"项目=蓝、画布=绿"——实现时按视觉调，看着舒服就行。
- 饱和度上限：实现时定，参考 Win11 Store 的克制多色（低饱和、高质感）。

## 5. Chrome 适配规则（替换 ad-hoc `!important`）

### 5.1 当前问题

当前每个预设用 `[data-style="..."] !important` 零散覆盖 `#topbar`/`#side-panel`/`#dockBar`，是手搓的、非标准化的，导致 bug 多、维护低效。

### 5.2 新规则：变体驱动 chrome

chrome 覆盖由**材质变体**驱动，不是由单个预设驱动。同变体的预设共享 chrome 规则，只在圆角/字体/配色模式上有差异。

#### Fluent 变体 chrome（clear, bento, editorial）

```
#topbar:
  background: Mica 实色 (92–98%) + 极淡纵向渐变
  backdrop-filter: none  ← 不用
  border-bottom: 1px solid var(--card-border)
  box-shadow: 0 1px 0 rgba(255,255,255,.9)  ← 极淡，仅顶部高光
  noise: ON (L3 叠加)

#side-panel:
  background: Mica 实色 + 纵向渐变
  backdrop-filter: none
  border-right: 1px solid var(--card-border)
  ::before: none  ← 砍掉当前装饰性径向光晕

#dockBar:
  background: rgba(255,255,255,.82)
  backdrop-filter: blur(22px) saturate(180%)  ← 小面积悬浮，OK
  border: 1px solid rgba(255,255,255,.94)
  box-shadow: 多层投影 + inset 顶部高光
```

#### Fluent 变体 chrome — glass 子变体

```
#topbar:
  background: rgba(255,255,255,.55)  ← 薄
  backdrop-filter: blur(30px) saturate(190%)  ← 满毛玻璃
  border-bottom: 1px solid rgba(255,255,255,.3)

#side-panel:
  background: rgba(255,255,255,.5)
  backdrop-filter: blur(28px) saturate(170%)

#dockBar:
  background: rgba(255,255,255,.5)
  backdrop-filter: blur(24px) saturate(180%)
```

#### 拟态变体 chrome（neumorph, colorful）

```
#topbar:
  background: var(--surface)  ← 均匀实色 (#f2f3f6 / #2e2e34)
  backdrop-filter: none
  border: none
  box-shadow: var(--shadow-sm)  ← 双向柔影 (2px 2px 6px dark, -2px -2px 6px light)

#side-panel:
  background: var(--surface)
  backdrop-filter: none
  border: none
  box-shadow: var(--shadow-sm)
  ::before: none

#dockBar:
  background: var(--glass)  ← 同表面色
  backdrop-filter: none
  border: none
  box-shadow: var(--shadow-md)  ← 双向柔影，比 chrome 更深
```

#### 反材质 chrome（minimal）

```
#topbar:
  background: var(--surface)  ← 纯实色
  backdrop-filter: none
  box-shadow: none
  border-bottom: 1px solid var(--card-border)

#side-panel:
  background: var(--surface)
  backdrop-filter: none
  box-shadow: none
  border-right: 1px solid var(--card-border)
  ::before: none

#dockBar:
  background: var(--surface)
  backdrop-filter: none
  box-shadow: none
  border: 1px solid var(--card-border)
```

### 5.3 预设级差异（变体内）

同变体内的预设差异**只通过 CSS 变量参数化**，不再整块 `!important` 覆盖：

```css
/* 变体级规则定义材质处理 */
[data-variant="fluent"] #topbar { /* Mica 规则 */ }
[data-variant="neumorph"] #topbar { /* 柔影规则 */ }
[data-variant="minimal"] #topbar { /* 平实规则 */ }

/* 预设级只调参数 */
[data-style="bento"] { --radius-md: 20px; --color-mode: multi; }
[data-style="editorial"] { --radius-md: 4px; --color-mode: multi; --font-preset: serif; }
```

> **迁移要点**：引入 `data-variant` 属性（在 `<html>` 上，与 `data-style` 并列），由 `applyStyle()` 根据预设映射设置。chrome 规则绑定到 `data-variant`，预设级只调圆角/字体/配色模式变量。

## 6. 节点处理规则（L6）

### 6.1 分档待遇

| 档位 | 适用节点 | 处理 |
|---|---|---|
| 全套 | 根节点 / 主分支节点 | 渐变 + 溢出色块 + backdrop-filter + hover 光 |
| 简化 | 叶节点 | 渐变 + 轻 hover 亮度变化，无溢出层，无 backdrop-filter |

> 分档规则必须实现前定死。mind map 可能有几十上百节点，每个都套全套会卡顿。

### 6.2 每变体的节点绘制

**Fluent 变体（clear / glass / bento / editorial）：**
- 全套节点：渐变填充 + 背后溢出色块（`blur(30px)`，比节点大一号）+ `backdrop-filter` Acrylic + hover 跟随光（`radial-gradient` at `var(--x) var(--y)` + `mix-blend-mode: screen`）
- glass 额外：对角高光带 + 底部反射条
- 简化节点：渐变 + 轻 hover 亮度
- 圆角按预设：clear=8, glass=14, bento=20, editorial=4

**拟态变体（neumorph / colorful）：**
- 全套节点：`drawNeumorph()` / `drawColorful()`——双向偏移阴影（亮左上 + 暗右下），平色表面，选中改内凹
- colorful 额外：彩色表面（`shadeColor(it.color, 1.15)`），白色文字
- 简化节点：单向阴影 + 平色
- 圆角：neumorph=14, colorful=16

**反材质（minimal）：**
- 全部节点：平色填充 + 细边框（按层级深浅），无渐变/阴影/发光
- 字号缩放 1.14×（靠类型层级代替装饰）
- 圆角：4px

## 7. 性能预算

### 7.1 常开层（便宜，固定成本地板）

| 层 | 成本 | 说明 |
|---|---|---|
| L1 漂移色 | 低 | 3–5 个 div 的 CSS transform 动画，GPU 合成层 |
| L2 Mica | 极低 | 静态背景色 + 渐变 |
| L3 噪点 | 极低 | 一个共享 SVG data URI |
| L4 图案 | 极低 | 静态 CSS pattern |

### 7.2 按需层（重，分档/按需触发）

| 层 | 成本 | 触发 |
|---|---|---|
| L6 溢出色块 | 中 | 仅根/主分支节点 |
| L6 backdrop-filter | 高 | 仅根/主分支节点；glass 变体可能需要伪造 Acrylic（见 §8.2） |
| L6 hover 光监听 | 中 | per-element mousemove，用 rAF 节流 |
| L7 chrome backdrop-filter | 高 | 仅 glass 变体；其他变体 chrome 不用 |

### 7.3 禁止项

- ❌ 大面积 chrome（顶栏/左栏）用 `backdrop-filter`——除 glass 变体外
- ❌ 所有节点都套全套处理——必须分档
- ❌ 背景动画跟画布 pan/zoom 走——L1–L4 固定视口

## 8. CSS 陷阱与约束

### 8.1 `mix-blend-mode` 与层叠上下文

父元素有 `transform` / `filter` / `will-change` / `opacity < 1` → 创建独立层叠上下文 → 子元素的 `mix-blend-mode` 只在上下文内部混合，不和下层真正融合 → hover 光"贴在卡片上"而不是"和下层渐变融在一起"。

**对策**：需要混合的层放在同一层叠上下文，或用 `isolation: isolate` 显式管理。hover 光效做出来像"贴白塑料"的最常见原因就是这个。

### 8.2 `backdrop-filter` 与父级 transform

画布 pan/zoom 用 `transform` → 破坏 `backdrop-filter` 采样 → Acrylic 失效或闪烁。

**对策（二选一，实现前定）**：
- (A) 节点不用真 `backdrop-filter`，用伪造 Acrylic——在节点底层直接画一个模糊色块（手动 `filter: blur()` 或预渲染），不靠真 backdrop-filter 采样。视觉接近，性能更好，无闪烁。
- (B) 节点放在一个不 transform 的容器里，pan/zoom 改用其他方式（如 margin/offset）——不现实，性能差。

**倾向 (A) 伪造 Acrylic。** 决定后写死，不在实现中途发现再改。

### 8.3 `isolation: isolate` 管理

对需要内部 blend 自洽的区域（如单个卡片的 hover 光 + 渐变 + 溢出），在卡片容器上设 `isolation: isolate` 创建隔离上下文，避免卡片间互相 blend。
