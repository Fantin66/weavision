# 织见 · 项目交接手册

> 版本：v1.0 | 日期：2026-08-30 | 面向：接手项目的 GPT / 开发者
> 目标：无需额外沟通即可独立上手

## 一、项目背景

**织见（Weavision）思维关系板**是一个单文件 HTML 应用：把"思维导图"升级为"思维关系网"——支持思维导图节点、便签、材料卡片、画笔五种元素，5 种语义连接（关联/支撑/导致/反证/证据）、批注、展开内容（Markdown）、附件形变预览、7 种自动布局、5 套视觉风格、聚焦模式、沉浸模式、AI 编排接口（`window.ZhijianAI`），并内置"织见学堂"教学项目。

- **定位**：投研/战略/产品规划知识工作者；10 分钟完成"放证据→写判断→连结论→聚焦复核"闭环
- **核心理念**：连接织宽（网）、聚焦钻深（点）
- **技术形态**：单文件 `织见-思维关系板.html`（约 13 万行内联 JS+CSS+HTML），零构建、零依赖
- **交互乐趣**：教程本身就是织见作品——教程画布用语义连接讲"连接"，用聚焦讲"聚焦"

## 二、技术栈

| 层 | 技术 |
|---|---|
| 界面 | 原生 HTML5 + CSS3（CSS 变量主题、毛玻璃 backdrop-filter、Canvas 2D 绘制画布） |
| 逻辑 | 原生 JavaScript（无框架、无打包器） |
| 持久化 | localStorage（项目/画布结构）+ IndexedDB（附件 blob，DB=boardlib / store=files） |
| 预览渲染 | 自研 Markdown 渲染器（mdToHtml/mdInline，防 XSS）+ CDN 组件（docx-preview/pdf.js/xlsx，可离线放入 assets/vendor） |
| AI 接口 | `window.ZhijianAI`（v1.2）：snapshot / execute（31 命令）/ buildCanvas |
| 测试 | Playwright（无头 Chromium 加载 file:// 做自动化验证） |

**核心约束**：
1. HTML 与 `assets/` 必须同目录（相对路径引用 6 字体）
2. 全部功能在**单个 `<script>`** 内——改代码后语法校验法：`node --check`（提取 script 内容）
3. 状态由 `localStorage["board-state"]` 持久化；无存档时 `seed()`+`seedTutor()` 生成两个项目（商业航天总纲 + 织见学堂）

## 五、常见工作流程

### 流程 A：修改功能 → 验证
1. 编辑 `织见-思维关系板.html`
2. 语法校验：`node -e "const fs=require('fs');const h=fs.readFileSync('织见-思维关系板.html','utf8');const m=h.match(/<script>([\s\S]*?)<\/script>/);fs.writeFileSync('_ck.js',m[1]);" && node --check _ck.js`
3. Playwright 加载 `file:///...织见-思维关系板.html` 做行为验证（注意每会话全新上下文，localStorage/IDB 不持久）
4. 有意义的改动做备份：`Old/织见-全量备份-<时间戳>/`

### 流程 B：新增一个功能菜单项
1. 在 `ICON` 加 SVG 图标（统一 stroke=2 线性风格）
2. 在 `MENUS.xxx` 或 `renderDock` 的 dkBtn 列表注册入口
3. 实现回调：`pushHistory→改 state→render→saveState`
4. 若影响布局：确保走 `applyAutoLayout`/`avoidOverlap` 统一链

### 流程 C：AI 接口新增命令
1. `aiExecute` 的 switch 加 case（op 命名要下划线风格）
2. `aiSnapshot` preferences 如有新偏好同步
3. 更新 `references/api.md` + 版本号 `ZHIJIAN_AI_API_VERSION`
4. 同步两份 skill 副本（织见/4- + ~/CodexData/.codex/skills/）

### 流程 D：改教程内容
- 教程是 HTML 内 `seedTutor()` 生成的「织见学堂」项目，改动需同步到 seedTutor 的构建代码
- 附件为 base64 内联（`ATT` 数组）；改附件需重新 base64 编码
- 教程文案在 seedTutor 内的 detail/annotation 字段
