- 表格预览：SheetJS 解析前将 IndexedDB/导入链路返回的 `Blob` 转为 `ArrayBuffer`，修复 Excel 被误报“表格解析失败”。
- 重新排版：固定遵循当前选定布局；移除布局后全局逐项避让（会拆散树结构）的调用；布局切换与重新排版均写入撤销历史。
- 可读性：节点标题按层级自适应宽度、自动折行和高度；展开详情不再按 80 字截断，按内容撑开并增加内边距。
- 布局升级：节点批注纳入树形子树占区；层级间距与同级间距加大，并预留父子主线与语义关系线通道；内置「织见学堂」首次写入及旧存档迁移均改走树形自动布局。
- 批注统一：节点、附件、便签、画笔和语义连接线统一为带色条的轻量说明卡，不再同时存在“裸文字”和“线专属 callout”两种形式。
- 连线统一：层级线与语义连接线沿用同一条方向感知路径、风格笔触与箭头规则；关系类型仅以颜色、虚实和箭头表达。
- 配色模式：样式面板新增「统一单色 / 自动轮换」；自动轮换会让相邻子节点按色板交替，且避开父节点当前颜色。

仍需在本机浏览器完成真实交互回归：展开/形变、多预览、网页 iframe、Word/PDF/表格预览、触控板与窄屏。

## 关键变更明细

### 1. 素材与主题（08-29）
- **Xmind 反向解析**：解包 Xmind exe（7z SFX）→ 提取 resources/app.asar（用 @electron/asar）→ 拿到 8 套主题 JSON + 6 款字体
- 落地：`assets/themes-xmind-精选.json`、`assets/fonts/`、FONT_PRESETS 扩至 5 预设
- **整图导出 PNG**：离屏 canvas + 内容包围盒 + 2x 倍率限 8192px

### 2. 预览体系（反复迭代的核心区）
- **缩放同步公式**（最终版）：iframe 100% 撑满 + CSS `zoom`（画布 zoom × 用户 pvZoom）；手机模式 375 逻辑宽
- **踩坑**：`transform scale` 会裁剪内容破坏滚动 → 改 CSS zoom（布局级）解决
- **踩坑**：morphDom 全局单例 → 多形变切换白屏 → 改 `morphMap` 多实例
- **踩坑**：board wheel 全局 preventDefault → 预览内滚动失效 → 浮层放行
- **踩坑**：iframe `no-referrer` → 图床/视频防盗链拒绝 → 改 `no-referrer-when-downgrade` + allow 媒体声明
- **文档渲染**：自研 mdToHtml/mdInline（防 XSS 微渲染），docx/pdf/xlsx 走 CDN

### 3. 布局引擎（08-30 升级）
- 新增 `LAYOUT_SPEC` 参数体系（gapX 深度递增 / gapY 密度放大 / 最小尺寸 / 安全边距）
- 新增密度预扫描 `layoutSpec()` + 方向决策 `decideLayoutDirection()`（右→双向分叉→下展）
- 双向分叉 `translateSubtree()`（含附属平移）
- 全布局尾部收敛式 `avoidOverlap()`（防重叠保证）

### 4. 视觉体系（渐次统一）
- 图标统一 SVG 线性（删 emoji 混用：🎨⛶☐⇲✎→ICON 库）
- 批注纯文字化 + 四向定位 `computeAnnotationPos`
- 展开内容把手去蓝底胶囊改中性
- 默认色墨蓝→正蓝；默认字体雅黑→宋体；字体与 UI 分离

### 5. AI 接口（v1.1）
- `window.ZhijianAI`：snapshot / execute（27 命令：create_*/relate/attach/set_layout/set_style/set_preferences/focus/undo/batch 等）/ buildCanvas
- 配套 skill：zhijian-canvas-orchestration（双份：织见/4- + CodexData/.codex/skills/）

### 6. 织见学堂（内嵌教程）
- `seedTutor()` 无存档时自动生成「织见学堂」（4 画布 + 6 内联附件入 IDB）
- 旧存档兼容：无学堂时也补生成
- 教程文案：便签比喻叙事风格

### 7. 收纳与文档
- Interest 顶层 40+ 散落文件 → `织见/` 四目录（旧版/新版本/手册/skill）

### 8. 画布信息层级与布局模板（08-30 傍晚）
- **批注**：由白色卡片回归为无底色、无边框的文字；仅当前选中节点或其相邻关系的批注高亮，其他批注降为低透明度。批注保留轻量引线/锚点，减少归属歧义。
- **连线**：层级线与语义连接统一使用同一矢量路径系统；默认层级线降噪，选中节点/语义关系时加深并显示沿线方向的关系说明。
- **展开内容**：改为高对比、不受节点底色干扰的阅读面，避免出现文字与背景同色。
- **跃迁**：节点内展示明确的“↗ 跳转”小控件；点击即切换目标画布并把视角定位到目标节点。
- **布局**：移除“逻辑图向左/向右/向上/括号树”等方向性菜单；保留逻辑图（拖拽决定左右分支）、组织架构图、鱼骨图、时间轴四种模板。组织架构图使用正交折线。

## 踩坑记录（含解决）

| # | 问题 | 根因 | 解决 |
|---|---|---|---|
| 1 | Word 预览内容显示不全/无法滚动 | board wheel 全局拦截 + docx 容器高度溢出 | wheel 浮层放行 + overflow:auto |
| 2 | 网页预览白屏（多形变切换） | morphDom 单例被反复销毁重建 | morphMap 多实例 |
| 3 | 图片/视频加载不出 | iframe no-referrer 被防盗链拒 | no-referrer-when-downgrade + allow |
| 4 | 切样式 UI 字体跟着变 | applyFontPreset 写 --font 全局变量 | 只改画布 FONT，UI 不动 |
| 5 | 教程写入节点全重叠 | 批量写 state.items 绕过拖拽避让链 | seed 收尾收敛式 avoidOverlap |
| 6 | seedTutor 未定义 ReferenceError | 插入锚点错位嵌套进 seed() | 闭合前置修复 |
| 7 | Playwright 数据不持久 | 每会话全新上下文 | 改为内嵌 seed 而非外部构建 |
| 8 | 批量移动出现 assets/assets 嵌套 | mv 到已存在目标 | 手动上移修复 |
| 9 | 批注被误解为"藏蓝块" | 展开内容把手蓝底胶囊误认 | 把手改中性、批注纯文字 |
| 10 | 编辑态 Dock 工具栏消失 | open/close 编辑器未调 renderDock | 三处补 renderDock(true) |
| 11 | avoidOverlap 重复定义 | 历史残留两份相同函数 | 删一份 |
| 12 | 高亮层/浮层内滚动触发画布平移 | wheel 未区分目标 | 浮层选择器放行 |
