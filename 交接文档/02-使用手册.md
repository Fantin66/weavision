# 织见（Weavision）使用手册

> 适用范围：织见·思维关系板 v1.0（2026-08-30 快照，含 AI 接口 v1.2）
> 版本：v1.0 | 原文：`织见-思维关系板.html` 内嵌功能；关联文档：《项目总纲白板-产品设计手册.md》（设计理念）、《织见使用教程-设计方案.md》（内嵌教程设计）
> 说明：本手册为**外部使用文档**；应用内另有"织见学堂"教学项目（打开即见），二者内容互补——本手册适合通读，学堂适合边做边学。

## 一、快速开始

1. 打开 `织见/2-新版本及其素材/织见-思维关系板.html`（浏览器直接运行，无需安装）
2. 首次打开自动生成两个项目：**商业航天总纲**（示例）、**织见学堂**（使用教程）
3. 左侧栏切换项目/画布；画布空白双击新建节点
4. 10 分钟上手路径：建节点（Tab 子级）→ 连关系（C）→ 写批注（A）→ 聚焦（F）→ 看全局（适应全部）

### 概念速记
- **节点**：思维导图的主体，可层层嵌套
- **便签**：零散想法（不占层级）
- **材料卡片**：文件/链接进画布
- **语义连接**：节点间的"关系线"，带类型与批注
- **聚焦**：只看某个点及其直接关系，再退回来

## 三、节点与层级（思维导图）

| 功能 | 操作 |
|---|---|
| 新建节点 | 空白双击；**Tab=子级、Enter=同级** |
| 调整顺序 | Alt+↑↓ 同级排序 |
| 提级/降级 | Alt+←→ |
| 折叠子树 | 节点右侧 −/+数量把手 |
| 节点右缘蓝点 | 拖到节点=设为子级；拖到便签/卡片=自由连接 |
| 4 级视觉降级 | 根=实心、一级=白底彩边、二级=白底竖条、三级=透明灰 |
| 自动布局 | 布局菜单：逻辑图右/左、组织、U型、鱼骨、时间轴、括号（7 种） |
| 重新排版 | 布局菜单末位"重新排版"（一键规整全图） |

**布局自适应**：并列节点多时会自动放大间距（≥6 个触发疏散）；空间不足时自动切换方向（右→双向分叉→下方展开），保证不重叠。

## 六、连接与语义

| 功能 | 操作 |
|---|---|
| 连接选中 | 选中两个元素按 C（或 C 取消） |
| 连接类型 | 5 种：**关联 / 支撑 / 导致 / 反证 / 证据**（右键改） |
| 方向与批注 | 支撑/导致/反证自动带方向；连接上可加批注 |
| 关联挂接 | 便签/材料拖到节点 = 成为支撑材料（角标计数） |
| 批注 | A 键加一句话批注（纯文字，自动避让定位） |
| 展开内容 | E 键编辑 Markdown detail（元素自带阅读区，右缘文档把手） |
| 画笔 | P 键手绘涂鸦（质感随样式联动） |
| 自定义连线 | 元素间/自由锚点连线，可挂批注 |
| 跃迁 | J 键设目标画布+元素，之后按 J 直达（左下角 ↗） |

## 七、布局 / 样式 / 背景

### 布局（布局菜单）
7 种自动布局 + 重新排版；密度自适应与方向自动切换（见第三节）。

### 样式（样式菜单）
| 样式 | 说明 |
|---|---|
| 默认 | 清晰层级与统一卡片轮廓（默认） |
| 玻璃 | 有厚度的磨砂玻璃、冷光边与配套连线 |
| 拟物 | 不透明纸张、墨水连线与自然纸边（切换自动配手写字体） |
| 简约 | 极简边框，字号/颜色分层（切换自动配宋体） |

### 字体（查看菜单）
5 种独立切换：**界面雅黑 / 书卷宋体（默认）/ 手写楷体 / 艺术手写 / Montserrat 雅黑**。
界面 UI 字体固定不随样式变，字体只影响画布内文字。

### 背景（背景菜单）
底色 5 种（默认/护眼/米白/浅蓝/牛皮纸）× 纹理 4 种（网格/圆点/纸纹/纯色）。

## 十、AI 协作（进阶）

应用为 AI 预留同页接口 `window.ZhijianAI`（版本 v1.2），在开发者控制台（F12）可用：

```js
// 读取当前项目全貌
window.ZhijianAI.snapshot()

// 单条命令（27 种）
window.ZhijianAI.execute({op:"create_node", title:"新节点"})
window.ZhijianAI.execute({op:"set_style", style:"paper"})
window.ZhijianAI.execute({op:"set_layout", layout:"org"})

// 一次生成整张画布
window.ZhijianAI.buildCanvas({
  title:"主题",
  nodes:[{key:"root",title:"根"},{key:"c1",parentKey:"root",title:"子1"}],
  relations:[{from:"root",to:"c1",type:"supports"}]
})
```

**常用命令**：snapshot / activate / create_project / create_canvas / create_node / create_note / create_attachment / update_item / relate / attach / detach / reparent_node / set_layout / set_style / set_preferences / focus / undo / redo / batch …（完整 31 命令清单见配套 skill 的 `references/api.md`）

**调用顺序建议**：snapshot 看现状 → 组织好 plan → buildCanvas 生成 → 用返回 aliases 补连接。

> AI 生成的画布会自动做重叠收敛（生成后走统一避让机制）。

## 十二、常见问题（精简）

1. **点开 Word/PDF 白屏**：预览组件走 CDN，需联网；离线可把组件放 `assets/vendor/`
2. **网页图片加载不出**：若目标站有防盗链，织见已带 Referer 策略；仍失败请在新窗口打开
3. **多个附件预览互相干扰/白屏**：已改为多实例并行，各预览独立
4. **切样式字体"没变回来"**：字体与样式已分离——只有"拟物/简约"会配专属字体，其余保留你手动选的字体
5. **布局乱/重叠**：点"重新排版"，或切换布局触发自动避让与疏散
6. **编辑状态工具栏消失**：之前已修复（编辑态 Dock 正确切换）
7. **框选**：开启下 Dock“框选”后，拖空白区域选择；点击元素累加；拖任一已选元素可整体移动；Ctrl/Cmd+点击已选元素可移出选择。
