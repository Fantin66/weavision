## A. 附件 / 网页预览类

### A1. Word/文档预览内容显示不全、无法滚动
- **背景**：用户多次反馈"打开 Word 附件显示不全、无法滑动；全屏也不行；滚轮反而平移画布"
- **已有方案**：①board wheel 处理器放行浮层内滚轮（#previewLayer/#fullscreenView 等）；②docx 容器限高可滚 + 宽度自适应（img max-width）
- **失败尝试**：仅加 overflow:auto 不解决 wheel 被全局拦截的问题——必须同时放行事件

### A2. 同时打开多个附件形变预览 → 网页预览白屏
- **背景**："多附件形变预览下的网页预览中断，聚焦某文件导致白屏"
- **根因**：morphDom 全局单例，切换时销毁重建唯一 iframe
- **已解决**：morphMap 多实例（每卡片独立覆盖层 + token 防竞态）

### A3. 网页预览图片加载慢 / 视频无法播放
- **背景**："图片有时加载不出来，视频也无法播放"
- **根因**：iframe `referrerPolicy="no-referrer"` → 图床/视频站防盗链拒绝；无 allow 媒体声明；视频 preload=metadata
- **已解决**：三处 iframe 改为 `no-referrer-when-downgrade` + `allow="autoplay; encrypted-media; picture-in-picture"`；img/video 同策略；视频 preload=auto

### A4. 拖拽调整预览尺寸后内容被剪切
- **已解决**：resize up 后 `reflowPreview()` 触发 DOM reflow + 重新适配绘制

### A5. 预览长边贴合过紧无缝隙
- **已解决**：非 iframe 预览统一留白（padding 10px 12px）

## B. 字体与样式类

### B1. 切换样式时字体"没变回去"
- **根因**：applyStyle 曾把风格强绑字体，且 applyFontPreset 改写 UI 全局字体变量
- **已解决**：①字体与 UI 分离（--font 不再被写）；②仅"拟物/简约"两样式配专属字体，其余保留用户选择；③字体随时可经"查看→字体"独立切换
- **失败尝试**：原有 "fluent→Montserrat / minimal→雅黑" 强联动——用户明确不满意，改为分离

### B2. 默认字体期望宋体
- **已解决**：`fontPreset` 默认 "serif"（书卷宋体）

### B3. 默认颜色墨蓝太丑
- **已解决**：MIND_COLORS[0] 墨蓝 `#3a4a6b` → 正蓝 `#2d5fd3`

### B4. 样式体系去 Fluent、改名
- **已解决**：Fluent 删除（STYLE_ALIAS 映射旧存档→玻璃）；清晰→默认、玻璃拟态→玻璃、拟物手作→拟物

## C. 布局与避让类

### C1. 节点重合、自动避让不触发（教程写入场景）
- **背景**："手动拖动能避让，教程写入后全失效"
- **根因**：批量程序化生成绕过拖拽事件链，localAvoid 不触发
- **已解决**：批量写入（seedTutor）收尾逐画布**收敛式多轮** avoidOverlap；applyAutoLayout 尾部同样收敛防重叠
- **失败尝试**：仅 fitAll()（缩放视口）解决不了重叠

### C2. 批注位置异常、遮挡其他元素
- **已解决**：computeAnnotationPos 四向探测零重叠；全碰撞时选重叠最少方向并推开最近邻（WeakSet 防振荡）

### C3. 布局拥挤时希望自动疏散、多方向
- **已解决**：LAYOUT_SPEC 参数体系（密度≥6 放大间距）；decideLayoutDirection 右→双向分叉→下方；7 布局统一接入

### C4. 密集场景（三级四级节点多）挤在一起
- **已解决**：密度预扫描在布局前计算 gapY 放大（封顶 40+额外 10）；鱼骨图间距加大修复回首重叠

## D. 教程与写入类

### D1. "织见学堂"没看到，只有商业航天
- **根因**：有旧存档时 init 跳过 seed → 教程不生成
- **已解决**：有存档时检测无学堂也补生成 seedTutor

### D2. 教程写得太像工程文件、生硬
- **已解决**：文案重写为便签比喻叙事（"线=观点""一盏灯对准便签"）

### D3. 教程写入应走 skill 接口吗
- **背景**：复盘发现教程构建是代码直接生成，未走 `buildCanvas`
- **结论**：seed 冷启动必须内嵌，不依赖 skill；但暴露 skill 缺"生成后避让收敛"规范——已补进 SKILL.md

## E. 视觉与界面类

### E1. 上/下 Dock 分类混乱（样式里有背景）
- **已解决**：背景独立 tab；样式菜单纯净；三入口（上菜单/下Dock/视图按钮）一致

### E2. 图标风格不统一（emoji vs SVG）
- **已解决**：ICON 库补齐 8 个 SVG 线性图标，全入口统一

### E3. "重新排版"占版面太大/位置不对
- **已解决**：改为与其他布局同尺寸小格、末位附加项

### E4. 退出形变图标 × 不直观
- **已解决**：× 改上箭头胶囊钮

### E5. 全屏窗口与 Dock 重叠/错位
- **已解决**：applySide 末尾调 layoutFullscreen，Dock 切换即时重算

## F. 持久化与文件组织类

### F1. 素材散落在 interest 根目录太乱
- **已解决**：收纳为 `织见/` 四目录（旧版/新版本/手册/skill）+ README 说明

### F2. Playwright/无头环境数据不持久
- **背景**：外部 AI 或测试环境每次全新上下文，localStorage/IDB 空
- **方案**：Web 环境由应用自动持久化；无头环境需自行加载完整页面使 seed 生效
- **注意**：附件 blob 需写 IndexedDB（f.blob 内存也可）

## G. AI 接口类

### G1. 接口是否足够 AI 全面控制？
- **结论**：v1.1 足够（项目/画布/元素/关系/附件元数据/布局/样式/聚焦/撤销全覆盖）
- **已知缺口**（潜在风险，未修复）：无并发/超时防护（大 build_canvas 可能阻塞 UI）；create_attachment 不支持字节（AI 建的附件无真实内容）；无调用源校验

### G2. AI 生成画布重叠
- **已解决**：applyAutoLayout 尾部收敛避让 + SKILL.md 约定"生成后必须免重叠"
