```
织见-思维关系板.html
 ├─ 引用 assets/fonts/*.ttf（相对路径，同目录绑定）
 ├─ 内嵌 seedTutor() → 生成「织见学堂」项目（无存档时）

skill 文档 ↔ HTML 内 AI 接口（api.md 描述 ↔ 页面实现，同步维护）
设计手册 ↔ 实际功能（v6.4 记录的功能点 ↔ 代码实现）
```
