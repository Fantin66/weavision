# Demo B1 双 Skill 审美鉴定与全屏预览改造

## 设计判断

织见是高密度桌面知识画布，不是营销网站。此次采用“保留式更新”，不改信息架构、品牌蓝、画布操作习惯和资源库结构。

- 设计系统倾向：Fluent 式桌面产品界面 + 织见现有品牌语言
- DESIGN_VARIANCE：4，允许局部层次变化，但不做实验性排版
- MOTION_INTENSITY：4，只为状态切换、层级进入和操作反馈服务
- VISUAL_DENSITY：7，保持研究工具的信息密度，同时减少拥挤和重复装饰

## web-design-guidelines 审查结果

本轮优先修复：

1. 全屏入口与退出状态缺少统一的工作区边界。
2. 全屏仍保留左侧栏和底部 Dock，阅读任务被非必要控件干扰。
3. 全屏附件之间不能连续切换。
4. 多处使用 `transition: all`，会让无关属性参与动画。
5. 新增的图标按钮需要明确名称和可见焦点状态。
6. 动画需要支持 `prefers-reduced-motion`。

已完成：

- 全屏改为顶栏下方的直角工作区，移除浮窗圆角、边框和大阴影。
- 进入全屏时，左侧栏向左退出，底部 Dock 向下淡出；退出时恢复原状态。
- 新增附件标签栏，支持打开历史、切换、关闭和长标题截断。
- 清理页面中的 `transition: all`，改为只动画颜色、透明度与位移。
- 新增控件使用语义化按钮、可见键盘焦点和 `aria-label`。
- 在系统启用减少动态效果时关闭全屏位移动画。

## design-taste-frontend 鉴定结果

该 skill 明确说明其重点是营销页和品牌页面，不适合直接套用到仪表盘或高密度产品 UI。因此本轮只采用以下规则：

- 形状一致性：全屏容器与应用框架保持直角，工具按钮统一为 8px 小圆角。
- 卡片克制：全屏不再叠加玻璃卡片和大阴影。
- 动效有因：仅用位移表达“离开画布、进入阅读工作区”。
- 状态完整：补齐附件打开、切换、关闭、退出和减少动态效果状态。
- 保留式更新：不修改项目、画布、资源库的信息架构。

## 高清素材库取舍

本轮检查了 Tabler Icons 与 Phosphor Icons。两者均提供高质量矢量图标，适合桌面工具界面。

当前项目已经使用 24×24、2px 描边的线性图标语言，与 Tabler 的规格高度接近。新增附件标签和全屏控件继续沿用这一语言，避免同时混入两套图标风格。

没有引入照片、插画或装饰性背景素材。织见的核心内容由用户文件、网页和画布节点构成，额外高清图片会抢占注意力，也不符合高密度研究工具的用途。

## 网页预览 403

澎湃新闻首页在普通请求和模拟 iframe 请求下均返回 200，说明网址本身可用。旧版 iframe 沙箱缺少 `allow-same-origin`，会让部分网站失去正常的 Cookie、存储和跳转环境，可能被风控误判为异常嵌入。

本轮统一网页预览配置：

- 增加 `allow-same-origin`、下载、弹窗逃逸和用户触发顶层跳转能力。
- 保留沙箱，不允许远程页面无条件接管父窗口。
- Referrer Policy 改为 `strict-origin-when-cross-origin`。
- 画布预览、形变预览和全屏预览复用同一配置，避免三处行为不一致。

该修复不依赖 WPS、本地 Office 服务或新增后台服务。

## 回归重点

1. 刷新页面后重新展开“澎湃新闻”，确认不再出现 Zen/4.3 的 403 页面。
2. 连续全屏打开 Word、表格、图片和网页，确认顶部标签完整出现。
3. 切换标签后确认预览内容、标题和“默认应用打开”目标同步更新。
4. 关闭当前标签时自动切换到相邻标签，关闭最后一个标签时退出全屏。
5. 进入全屏后确认左侧栏、侧栏把手和底部 Dock 不再可交互。
6. 按 Esc 或“退出全屏”后确认原画布状态恢复。
