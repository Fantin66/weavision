# 织见 Weavision · 思维关系板

> 织连万象，见聚一隅。Weave the many, See the one.

本地优先的思维关系板桌面应用。不是制式的树状思维导图——元素与线任意组合，线带方向和语义，图大了就聚焦，要看全就展开。

## 核心特性

- **就地形变**：节点/附件在原位展开为阅读区，不弹窗、不跳转
- **五种语义关系**：关联 / 支撑 / 导致 / 反证 / 证据
- **聚焦切换**：只留直接关系，其余退为背景
- **板→文导出**：关系板结构转化为 Markdown
- **.fantin 文件格式**：ZIP 封装，含画布数据 + 附件
- **AI 编排接口**：37 条命令的 `window.ZhijianAI` 接口
- **Win11 Fluent Design 材质系统**：七层堆叠 + 三种变体
