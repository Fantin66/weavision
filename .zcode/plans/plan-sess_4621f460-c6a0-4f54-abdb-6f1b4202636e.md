每个插件的步骤：

4. 确认 `.zcode-plugin\plugin.json` 或 `.claude-plugin\plugin.json` 清单文件存在

## Phase 5: 安装 git 克隆类插件（4 个）

来源：`claude-plugins-official` 市场，需从 GitHub 克隆

| 插件 | 仓库 | 固定 commit | 缓存路径 |
|---|---|---|---|
| `chrome-devtools-mcp` | `https://github.com/ChromeDevTools/chrome-devtools-mcp.git` | `6e56c028...` | `cache\claude-plugins-official\chrome-devtools-mcp\0.0.0\` |
| `remember` | `https://github.com/Digital-Process-Tools/claude-remember.git` | `31626fd2...` | `cache\claude-plugins-official\remember\0.0.0\` |
| `superpowers` | `https://github.com/obra/superpowers.git` | `d884ae04...` | `cache\claude-plugins-official\superpowers\0.0.0\` |
| `desktop-commander` | `https://github.com/wonderwhy-er/DesktopCommanderMCP.git`（subdir `plugins/claude`，sha `0ad919bc...`） | `0ad919bc...` | `cache\claude-plugins-official\desktop-commander\0.0.0\` |

每个插件的步骤：
1. `git clone` 仓库到临时目录
2. `git checkout` 到指定 commit
3. 复制到缓存路径（`desktop-commander` 仅复制 `plugins/claude` 子目录）
4. 确认清单文件存在

**风险**：git 克隆可能因网络/代理问题失败。若失败，会报告具体错误，可后续通过 GUI 手动安装。

## Phase 6: 注册插件到 installed_plugins.json

为每个成功安装的插件在 `C:\Users\99612\.zcode\cli\plugins\installed_plugins.json` 的 `plugins[]` 数组中添加条目。格式：

```json
{
  "id": "<name>@<marketplace>",
  "name": "<name>",
  "marketplace": "<marketplace>",
  "version": "<version or 0.0.0>",
  "installPath": "C:\\Users\\99612\\.zcode\\cli\\plugins\\cache\\<marketplace>\\<name>\\<version>",
  "installedAt": "<当前时间 ISO 8601>",
  "updatedAt": "<当前时间 ISO 8601>",
  "scope": "user",
  "source": <从 marketplace.json 复制的 source 对象>,
  "cacheTransactionId": "<新生成的 UUID>"
}
```

## 风险与回退

- **手动文件操作风险**：如果 JSON 格式不完全正确，插件可能无法被识别。回退方案：通过 ZCode GUI → Settings → Plugin Management → Discover 手动安装。
- **git 克隆失败**：网络/代理问题可能导致克隆失败。失败的插件会单独报告。
- **frontend-design 冲突**：本地 skill 和插件 skill 同名。如冲突可删除本地符号链接。
