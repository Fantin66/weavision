## 目录结构

```
织见/
├── 1-旧版本备存/           ← 历史版本与开发残留
│   ├── Old/               ← 全部历史备份（织见-全量备份-*/ 安全备份/副本/原型）

│   ├── assets/               ← 字体/主题/供应商组件（HTML 相对路径引用）

├── 3-设计指引手册/         ← 设计文档

│   └── 织见-前端设计优化分析.md

    └── zhijian-canvas-orchestration/  (SKILL.md + references/api.md 等)
```
